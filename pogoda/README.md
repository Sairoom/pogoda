# Погода — сайт кофейни

Одностраничный сайт кофейни «Погода» (Москва, Святоозёрская ул., 16).
React 19 + TypeScript + SCSS на базе Create React App.

## Запуск

```bash
npm install
npm start     # дев-сервер на http://localhost:3000
npm run build # продакшен-сборка в ./build
```

## Структура

```
public/
  images/          фотографии кофейни (см. images/README.md)
src/
  components/      секции страницы, у каждой свой .tsx + .scss
    ui/            переиспользуемое: Logo, Photo, Reveal
  data/            контент: контакты, меню, список фотографий
  hooks/           useReveal (появление при скролле), useScrollSpy
  styles/          переменные, миксины, глобальные стили
```

Весь текстовый контент вынесен в `src/data/` — чтобы поправить цену или
телефон, лезть в разметку не нужно.

## Что нужно заполнить перед публикацией

1. **Фотографии.** Положите снимки в `public/images/` под именами из
   [`public/images/README.md`](public/images/README.md). Пока файла нет, на
   его месте показывается тёплая заглушка — вёрстка не ломается.
2. **Контакты.** В [`src/data/site.ts`](src/data/site.ts) помечены `TODO`:
   телефон, почта, ссылки на соцсети и график работы — сейчас там заглушки.
3. **Цены.** [`src/data/menu.ts`](src/data/menu.ts) собран с грифельных досок
   в зале; часть цифр на фото читается нечётко — сверьте с кассой.

## Особенности

- Секции проявляются при скролле через `IntersectionObserver`, всё уважает
  `prefers-reduced-motion`.
- Меню — табы по категориям с колонками объёмов 0,2 / 0,3 / 0,4 л.
- Галерея с лайтбоксом: стрелки, `Esc`, клик по фону.
- Карта — виджет Яндекса по адресу, ключ API не нужен.
